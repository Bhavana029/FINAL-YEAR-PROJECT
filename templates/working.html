Project Workflow

This system predicts a user's blood group using retinal fundus and sclera images through machine learning. The process is completely non-invasive and follows the steps below:

⬆
STEP 1

Image Acquisition

The user uploads retinal (fundus) and sclera images via the web interface.

◻
STEP 2

Preprocessing

Images are resized, normalized, and enhanced to remove noise and improve clarity.

🧠
STEP 3

Feature Extraction

Key features such as vessel density and scleral color metrics are extracted.

🧩
STEP 4

Feature Combination

Fundus and sclera features are merged into a single feature vector.

⚙
STEP 5

Model Input

The combined features are fed into a trained Deep CNN classifier.

✔
STEP 6

Prediction

The model outputs the most likely blood group with confidence score.

📊
STEP 7

Result Display

The predicted blood group is shown along with extracted features.

Features Used for Prediction

The system uses extracted features from the fundus and sclera images.

Fundus Vessel Density

Measures blood vessel pixel proportion indicating vascular richness.

Arteriolar–Venular Ratio (AVR)

Ratio between arteriole and venule diameters.

Vessel Redness

Color intensity indicating oxygenation levels.

Sclera Mean Hue

Average color value of sclera region.

Important: This system is designed for research purposes only and is not a replacement for laboratory blood tests.
